PORTFÓLIO — JOÃO DAVI
=====================

COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o Visual Studio Code.
3. Vá em Arquivo > Abrir Pasta e selecione a pasta extraída.
4. Abra o arquivo index.html.
5. Para visualizar, clique com o botão direito no index.html e escolha "Open with Live Server"
   (se tiver a extensão Live Server instalada), ou abra o index.html diretamente no navegador.

ARQUIVOS
- index.html: estrutura e conteúdo da página.
- style.css: cores, layout, efeitos e responsividade.
- script.js: menu mobile, animações e configuração do e-mail.

PERSONALIZE
- Em script.js, troque "seuemail@exemplo.com" pelo seu e-mail.
- Em index.html, edite a seção Sobre mim, habilidades e projetos.
- Os projetos exibidos são exemplos iniciais; substitua por trabalhos reais.
- O site usa Google Fonts, então a tipografia personalizada depende de conexão com a internet.

Tecnologias: HTML5, CSS3 e JavaScript puro.
